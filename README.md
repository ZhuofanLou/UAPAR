# UAPAR
UAPAR: Uncertainty-Aware Pedestrian Attribute Recognition via Evidential Learning

We propose UAPAR, an Uncertainty-Aware Pedestrian Attribute Recognition framework in troduces uncertainty quantification into Pedestrian Attribute Recognition for the first time. Unlike conventional deterministic methods, which fail to assess prediction reliability on low-quality samples, UAPAR effectively identifies unreliable predictions and thus enhances system robustness in complex real-world scenarios.
