## Introduction

**UAPAR** is an uncertainty-aware framework for **Pedestrian Attribute Recognition (PAR)** that estimates not only attribute predictions but also their reliability.

Unlike conventional deterministic PAR methods, which typically produce only attribute classification results, UAPAR introduces **Evidential Deep Learning** to quantify prediction uncertainty. This enables the model to identify uncertain and unreliable predictions, thereby improving the robustness and trustworthiness of pedestrian attribute recognition systems in challenging real-world scenarios, such as occlusion, blur, low resolution, and ambiguous visual cues.

## Highlights

- We propose **UAPAR**, an uncertainty-aware framework for Pedestrian Attribute Recognition.
- We introduce **Evidential Deep Learning** into PAR to estimate prediction uncertainty.
- UAPAR can identify unreliable predictions on low-quality or ambiguous pedestrian images.
- The proposed framework improves the robustness and reliability of PAR systems in real-world scenarios.
